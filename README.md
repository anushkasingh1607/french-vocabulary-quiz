# French Vocabulary Quiz

An interactive French vocabulary learning website built with HTML, CSS, and JavaScript.

## 🌐 Live Website

[Play the French Vocabulary Quiz](https://anushkasingh1607.github.io/french-vocabulary-quiz/)


## 🖥️ Preview

![French Vocabulary Quiz](Screenshot%202026-09-07%20212643.png)
## 📚 Features

- Four French learning levels: A1, A2, B1, and B2
- Multiple vocabulary categories
- Multiple-choice questions
- Randomized questions and answer options
- No repeated questions within a quiz session
- Score tracking
- Progress bar
- Instant feedback for correct and incorrect answers
- Final score and performance message
- Responsive design for different screen sizes

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
